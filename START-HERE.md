## Проверка локально

Требуется Node.js 22+.

```powershell
cd "C:\Users\Bagdat\OneDrive\Desktop\uyym_app"

npm test

npm run dev
```

Откройте `http://localhost:5173`. Без `.env` публичная часть открывается, а закрытые API честно отвечают, что внешние сервисы не настроены. Сервер разработки работает на `127.0.0.1:8787`, Vite передаёт ему `/api` через proxy.

## Подключение владельцем

1. Создайте Supabase и отключите публичную регистрацию. Примените шесть миграций из `supabase/migrations/` по имени, затем `supabase/backend-role.sql` по [инструкции владельца](docs/owner-guide.md). Для обновления с предыдущего этапа нужна только миграция `202610130006_submissions.sql`.
2. Скопируйте `.env.example` в `.env` и заполните серверные значения. Секреты, Google JSON, пароли, TOTP и recovery codes не коммитьте и не отправляйте в чат.
3. Выполните `npm run bootstrap`, сохраните recovery codes офлайн, войдите с временным паролем, смените его и зарегистрируйте браузер владельца с TOTP.
4. В ADMIN создайте преподавателя и ученика, курс, группу, назначение преподавателя и активное зачисление. После личной проверки одобрите заявку браузера ученика.
5. В Google Drive создайте отдельную Restricted-папку курса, включите Drive API и выдайте backend identity доступ Viewer только к этой папке. Добавьте папку и разрешённые email в `.env`.
6. Подготовьте реальный MP4: `npm run prepare-video -- "D:\Records\lesson.mp4" "work\prepared-video"`. Загрузите исходник, `init.mp4` и неизменённые `part*.m4s` в разрешённую папку.
7. В ADMIN → «Контент» создайте урок: выберите `manifest.json`, укажите Drive folder ID и Source MP4 file ID. Backend найдёт все сегменты пакетом по именам и проверит Restricted ACL, MIME и размер. ID каждого сегмента вручную вводить не требуется.
8. Там же опубликуйте условие домашнего задания и закрытые материалы Quiz/Midterm/Endterm/Final. Вложения до пяти файлов по 5 MB идут только в приватный `uyym-private` и выдаются через BFF. Сдача работы и оценивание в этом MVP отсутствуют.
9. Проведите реальную POC-приёмку по [чек-листу](docs/poc-acceptance.md): просмотр, перемотка, отказ второго браузера и прекращение выдачи новых частей после отзыва.

## Production

После успешной внешней приёмки выполните `npm run build` и `npm start` за HTTPS reverse proxy на одной Origin. Задайте `NODE_ENV=production`, `COOKIE_SECURE=true` и `APP_ORIGIN=https://ваш-домен`. Для локальной проверки собранного сайта используйте `APP_ORIGIN=http://localhost:8787` и не включайте production.

Платёжные данные и миграции сохранены для будущего, но раздел оплат скрыт из повседневной ADMIN-навигации. Никакие платные сервисы этим кодом не подключаются. Реальные Supabase, Drive, HTTPS, физические Chrome/Edge/Android/iPhone и восстановление backup должны быть проверены владельцем до запуска.
