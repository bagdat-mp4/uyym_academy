# Расходы и выбор размещения UYYM Academy

Проверено по официальным источникам 10 октября 2026 года. Это расчёт и инструкция выбора, а не заказ услуг. Платные ресурсы не активированы. У владельца пока нет подключённого Supabase и тестовой папки Drive; фактическая пропускная способность и сумма счёта не измерены.

## Рекомендуемый старт

Для POC используйте локальный Node.js 22+ BFF, Supabase Free и одну выделенную приватную папку Google Drive. Для учебного запуска перенесите этот же BFF на уже оплаченный владельцем сервер, если такой сервер есть и его условия разрешают выбранный объём видеотрафика. Наличие такого сервера сейчас не подтверждено. Иначе сначала выберите VPS или контейнерный хостинг с постоянным процессом, HTTPS, потоковыми ответами и явной квотой исходящего трафика. Подписку покупает владелец после POC.

Одна публичная HTTPS origin для фронтенда и `/api` упрощает cookies, CSRF и эксплуатацию. Reverse proxy должен передавать защищённые ответы без публичного кеша и без полного накопления видео в памяти/на диске. Для приватного API не используйте Cache Everything. Приложение проверяет новый proof и доступ на каждой части видео независимо от proxy.

React/Vite можно разместить отдельно на бесплатном статическом хостинге, однако это требует отдельно настроить домены, credentials, CORS, CSRF и cookies. Для первого запуска предпочтительнее BFF, который также отдаёт собранный `dist`. Бесплатный статический frontend не делает media backend бесплатным.

## Supabase

На дату проверки Free включает 500 MB базы, 50 000 MAU, 1 GB Storage, 5 GB исходящего трафика и отдельно 5 GB cached egress. Возможны два активных бесплатных проекта; неактивный Free проект приостанавливается после недели. Это внешние тарифные квоты, а не ограничение числа пользователей в коде. Для первых примерно 30 учеников metadata и небольшие задания могут поместиться в Free, но это оценка: следите за размером таблиц, вложений и исходящим трафиком. Видео хранится в Drive и через Supabase Storage не передаётся. [Тариф Supabase](https://supabase.com/pricing), [учёт исходящего трафика](https://supabase.com/docs/guides/platform/manage-your-usage/egress).

Телефон + пароль официально поддерживаются. Включите phone provider; создание каждого пользователя выполняет BFF через Admin API с `phone_confirm: true` после личной проверки номера владельцем. Это административное подтверждение, а не доказательство владения номером через SMS. Для выбранного процесса не вызывайте SMS OTP/signup/password-recovery flows. Не подключайте SMS провайдера. Проверка входа — server-side `signInWithPassword`, без передачи Supabase JWT/refresh token браузеру. [Телефон и пароль](https://supabase.com/docs/guides/auth/passwords), [Admin createUser](https://supabase.com/docs/reference/javascript/auth-admin-createuser).

Отключите **Allow new users to sign up** в общей конфигурации Auth: официально при отключении вход доступен существующим пользователям. Проверьте настоящим запросом, что самостоятельное создание пользователя отклонено, а Admin API продолжает создавать аккаунты. Закрытые таблицы/Storage/RPC остаются недоступными `anon` и `authenticated`; успешный прямой Supabase login не даёт права на материалы BFF. [Общая конфигурация Auth](https://supabase.com/docs/guides/auth/general-configuration).

Не рассчитывайте на бесплатную встроенную single-session настройку. Application session, одобренный ключ, одноразовые challenges, `auth_epoch` и сроки зачисления проверяет BFF через транзакции PostgreSQL. Подключение к БД должно использовать SSL и выделенную минимально привилегированную роль, а не `postgres` в повседневном runtime. Проверьте фактическую строку session pooler/direct connection в Dashboard; не вставляйте её в frontend.

## Google Drive

400 GB владельца — место для исходников. Эти 400 GB не являются тарифом бесплатной видеодоставки и не гарантируют доступность под нагрузкой.

Новый Google Cloud проект в октябре 2026 подпадает под модель квот, введённую 1 мая 2026. В текущей официальной таблице: 1 000 000 quota units/минуту/проект, 325 000/минуту/пользователь/проект и 1 TB исходящих данных в день. Отдельно опубликован daily billing threshold 400 000 000 units; подробности будущего биллинга обещаны позднее в 2026 с уведомлением минимум за 90 дней. Старые проекты, использовавшие API в ноябре 2025 — апреле 2026, могут сохранить прежние квоты. Проверяйте собственную консоль; не переносите старую цифру «12 000 запросов/минуту» на новый проект. `403/429` обрабатываются с backoff, а ошибки не превращают файл в публичный. В документации `files.get` указан как 5 units, `files.download` — 200; фактическое начисление для выбранных media запросов проверяется в Metrics. [Актуальные лимиты Drive API](https://developers.google.com/workspace/drive/api/guides/limits).

Создайте отдельную backend identity. Google официально допускает прямой sharing конкретного файла или папки с email service account без Workspace admin role и без domain-wide delegation. Дайте Viewer только выделенным курсовым папкам, если политика аккаунта владельца разрешает такое sharing. Не выдавайте service account роль администратора Google Cloud ради доступа к Drive. Ключ JSON хранится вне репозитория с ограниченными правами; предпочтительнее identity без долгоживущего ключа, если будущий хостинг это поддерживает. [Создание credentials и доступ к отдельным папкам](https://developers.google.com/workspace/guides/create-credentials).

`drive.readonly` даёт чтение доступных этой identity файлов; ограничение области обеспечивается sharing, серверным allowlist папок и проверкой родителей/permissions. Для OAuth владельца `drive.readonly` является restricted scope и может потребовать verification/security assessment. Не считайте OAuth запасным вариантом без этой проверки. `drive.file` уже по области, но требует подходящего выбора/добавления файлов приложением: простого подставления произвольного существующего file ID недостаточно. [Официальные scopes](https://developers.google.com/workspace/drive/api/guides/api-specific-auth).

Для каждой записи проверяются `parents`, MIME, размер и весь ACL файла и разрешённых папок, включая унаследованные разрешения. ACL может содержать `user`, `group`, `domain`, `anyone`; доступ детей наследуется от родителей, поэтому проверка только собственной записи файла недостаточна. Все principals должны быть ожидаемыми; `anyone`, неизвестные группы, домены или люди блокируют публикацию. Ученику Drive permission не выдаётся. [Sharing и наследование разрешений](https://developers.google.com/workspace/drive/api/guides/manage-sharing).

Blob MP4 можно читать через `files.get?alt=media` с `Range`. Выдавайте ограниченный диапазон потоком; не вызывайте `arraybuffer` на многочасовом исходнике. [Частичная загрузка и поток Node.js](https://developers.google.com/workspace/drive/api/guides/manage-downloads). Google file ID, bearer tokens, `webContentLink` и исходные media URL не включаются в student API.

## Cloudflare Workers: кандидат, не включённая услуга

Официальная страница, обновлённая 2 октября 2026, указывает минимум **$5/месяц** для Workers Paid, 10 млн запросов и 30 млн CPU ms в месяц; превышение — $0,30/млн запросов и $0,02/млн CPU ms. Отдельной платы за egress/bandwidth в Workers pricing нет. Итоговый счёт всё равно зависит от использования и других продуктов. Установите CPU limits и наблюдайте запросы, CPU и ошибки. [Workers pricing](https://developers.cloudflare.com/workers/platform/pricing/).

128 MB memory на isolate, 6 одновременных исходящих соединений на запрос и отсутствие жёсткого response-body-size limit не дают разрешения на произвольный бесплатный видеопрокси. Используйте streaming, короткие части и ограниченную конкуренцию. [Runtime limits](https://developers.cloudflare.com/workers/platform/limits/).

CDN условия от 28 сентября 2026 требуют подходящий платный продукт для видео/крупных файлов; Developer Platform назван среди примеров. Отдельная инструкция доставки видео от 25 августа рекомендует Stream или Enterprise Stream Delivery и прямо распространяет правила на публичный Cloudflare Tunnel. Developer Platform условия допускают временное ограничение ресурсов при чрезмерной нагрузке. Поэтому до выбора Workers для постоянного Drive relay подтвердите применимость именно платного варианта с описанием приватного потока и ожидаемого объёма. **$5 не является обещанием безлимитной видеодоставки.** Бесплатный orange-cloud CDN/Tunnel не используется для обхода этих правил. [CDN условия](https://www.cloudflare.com/service-specific-terms-application-services/), [доставка видео](https://developers.cloudflare.com/fundamentals/reference/policies-compliances/delivering-videos-with-cloudflare/), [Developer Platform условия](https://www.cloudflare.com/service-specific-terms-developer-platform/).

Текущий backend — Node.js/Fastify с `pg`, файловыми утилитами подготовки видео и прямыми SQL транзакциями. Он не поставляется как готовый Workers deployment. Перенос потребует адаптера runtime, проверенной PostgreSQL связи/Hyperdrive, secret bindings, отдельного размещения FFmpeg preprocessing и повторной проверки транзакций/плеера. Для первого POC это лишняя переменная; на уже имеющемся Node сервере можно проверить исходный код без миграции архитектуры.

## Оценка трафика

Для десятичных GB: `GB = число учеников × часы просмотра × битрейт Mbps × 3600 / 8 / 1000`. Учитывается суммарный аудио+видео битрейт. Это оценка payload; повторные просмотры, перемотка, транспортный overhead и неиспользованный буфер увеличивают её.

| Сценарий за полный курс | 1 Mbps | 2,5 Mbps |
| --- | ---: | ---: |
| Один ученик, 18 часов, один просмотр | 8,1 GB | 20,25 GB |
| 30 учеников, 18 часов, один курс | 243 GB | 607,5 GB |
| Те же 30, каждый смотрит все три курса | 729 GB | 1 822,5 GB |

Это объём **за 6 недель**, а не автоматически за один месяц. Три курса существуют в каталоге; расчёт на три курса не означает, что все 30 учеников на них зачислены. Одновременные 30 просмотров при 2,5 Mbps требуют примерно 75 Mbps исходящей передачи BFF плюс запас; BFF одновременно получает эти данные из Drive. Измерьте битрейт фактических записей и проведите согласованный тест. Квоты Drive API не заменяют гарантированную скорость video origin.

Небольшие части увеличивают число API запросов и DB proof checks. Для грубой оценки при частях по 6 секунд: `30 × 18 × 3600 / 6 = 324 000` media requests за курс, без challenge/heartbeat/metadata. Фактическое число зависит от формата, длительности частей и клиента. Это расчёт, не измеренный счёт.

## Домен через GitHub Student Developer Pack

На дату проверки Pack предлагает Namecheap `.me` на один год и SSL на один год, а Name.com — выбранные расширения, включая `.app`/`.dev`. Name.com подтверждает бесплатный первый год eligible TLD и Domain Safe. Применимость зависит от подтверждённого student status, выбранного имени и текущего redemption flow; общая конечная дата окончания предложения на просмотренных страницах не указана. [Pack](https://education.github.com/pack), [Name.com: условия первого года](https://www.name.com/de-de/support/articles/360036364834-signing-up-for-github-student-developer-pack).

Официальная общая таблица Namecheap сейчас показывает стандартное продление `.me` **$23,98/год**. Это ориентир для обычного непремиального имени, не подтверждённый счёт конкретного student bundle. На страницах nc.me встречаются отдельные bundle условия; перед оформлением прочитайте renewal quote именно своей корзины/аккаунта. Сохраните сумму, налог/сборы, дату окончания года и auto-renew setting. [Таблица Namecheap](https://www.namecheap.com/domains/), [страница GitHub offer](https://nc.me/landing/github), [bundle FAQ](https://nc.me/faq).

Числовую цену продления Name.com для выбранного домена пока подтвердить нельзя: домен не выбран, а их публичная таблица загружает числа динамически. Не закладывайте цену «$0 навсегда» или цифру из стороннего агрегатора. Проверьте поле Renewal для своего имени в [официальном pricing](https://www.name.com/pricing) и корзине. HTTPS можно выпускать через хостинг/ACME; покупка платного SSL дополнительно не требуется выбранной архитектурой.

## Что решить перед учебным запуском

- Создать бесплатный Supabase, проверить Auth, private schema и прямые запреты настоящими запросами.
- Создать Cloud проект, включить Drive API, выделить папку, настроить ограниченную identity и проверить реальный ACL.
- Подготовить один MP4 H.264/AAC с fast-start/нужной сегментацией; измерить воспроизведение и перемотку на целевых устройствах.
- Выбрать постоянный HTTPS backend; зафиксировать стоимость, outbound quota, лимиты соединений, резервное копирование и ответственность за обновления.
- Проверить выбранный домен, цену продления и дату окончания бесплатного года до оформления.
- Пройти `poc-acceptance.md`. Пока внешние тесты не пройдены, не объявлять закрытую видеоплатформу введённой в эксплуатацию.
