# Interface language and appearance

New visitors start in English with the light theme. EN / ҚАЗ / RU and the
theme toggle save preferences in the current browser. Existing language
choices remain in place. Disabled browser storage falls back to English/light.

The English catalog translates interface labels, actions, role panels,
application/sign-in forms and protected-player messages. Browser-native video
controls and native file-selection dialogs use the browser/operating-system language. Server errors requested in
English use safe messages without connection details.

Owner-entered content is displayed verbatim. Translate these separately if
English learning content is needed: course descriptions, group names and
schedules, lesson titles/descriptions/timecodes, assignment instructions,
announcements, exam archive topics/semesters, file contents, teacher bios,
public FAQ entries, student feedback and the website title. This release does
not overwrite or translate those database fields. The legacy KBTU-affiliation
FAQ is hidden even when supplied by website settings; stored settings are not
modified.

On #account, the header shows Back to home instead of the public section links.
The same rule applies to the mobile navigation. Authentication, browser proof,
TOTP, cookies and course permissions remain required.
